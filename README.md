# VideoMaster

片库是一个在浏览器里使用的抖音账号追踪和作品收藏本。它可以新增、编辑、删除账号，给账号写分组、批次、标签、备注和追踪状态；也可以单独收藏作品，粘贴抖音分享文案提取链接，再手写标题、作者、收藏夹、标签、评分、星标、笔记和观看状态。

仓库里没有后端、账号系统或数据库。数据写入当前浏览器的 `localStorage`，不上传，也没有云同步。

## 数据会怎样

- 只保存在当前浏览器。清除缓存、清除站点数据，或换浏览器、换设备，内容都不会跟着走。
- 首次打开会放入 40 个已锁账号（头部精品 20、怪异特异 16、观察 4），收藏夹是空的。
- 这 40 个账号里有 5 个搜索入口。页面会标成「搜索入口」，不会把它显示成已核实的作者主页。
- 备注里的粉丝数、作品数和剧名来自 2026-11-18 前后的记录，只是带日期的文字，不是实时统计，也不会变成已收藏视频。
- 删除账号后再刷新，不会把这 40 个账号自动种回去。要恢复时，用备份 JSON 合并导入。
- 删除账号默认保留已收藏作品，只解除关联。可以在确认框里另外选择同时删除关联收藏，删除后刷新前可以撤销。

## 作品链接

收藏只保存你填写的链接和文字。打开时跳到抖音原来的页面。本应用不内嵌播放，不下载，不抓取抖音页面，也不生成封面、播放量或粉丝数。

账号主页只接受 `http` 或 `https`，并且主机名必须是 `douyin.com`、`iesdouyin.com` 或其子域名，路径还得是 `/user` 或 `/search`。作品链接同样只接受这两个域名。`https://evil.com/douyin.com` 这种只是字符串里带有域名的地址不会通过。外链使用 `rel="noopener noreferrer"`。

## 备份

导出的 JSON 含有 `accounts` 数组、可选的 `works`，以及 `sourceTitle`、`sourceUrl`、`exportedAt`、`notes`、`fields`、`batchCounts`、`trackCounts`。当初的已锁账号文件可以直接合并导入。

导入会检查是否为 JSON、体积是否超过 2MB、结构是否有 `accounts` 数组。相同主页和相同作品链接会跳过。无法识别的条目会列出来，不会整份覆盖本地数据。损坏的本地记录不会被静默覆盖。

## 本地运行

需要 Node.js 20 或更新版本。

```bash
npm install
npm run dev
```

开发服务器默认是 `http://127.0.0.1:5173`。

```bash
npm test
npm run lint
npm run build
npm run preview
```

`npm run build` 会先做类型检查，再把静态文件输出到 `dist/`。

## 部署

这是纯静态站点，不需要环境变量，也不需要任何密钥。把 `dist/` 交给任意静态文件服务器即可，例如内网 Nginx：

```nginx
server {
    listen 80;
    root /var/www/videomaster/dist;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

如果站点不在域名根路径，构建前把 `vite.config.ts` 里的 `base` 改成对应子路径。用户的收藏仍然只在各自浏览器里，服务器上看不到这些数据。

本次没有做公网部署，也没有开通付费服务。
